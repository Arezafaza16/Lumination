# LUMINATION — Visual Storytelling & Fine Art Photography

![Lumination Hero](/public/images/hero.png)

## Overview

**Lumination** is a premium, high-contrast photography portfolio designed for the modern visual artist. Built with a focus on cinematic aesthetics, black-and-white photography, and dramatic lighting, this project showcases the intersection of reality and abstraction.

The application features a smooth, immersive user experience powered by GSAP animations and a minimalist design philosophy.

## ✨ Features

- **Cinematic Hero Experience**: High-impact, low-light architectural visuals with parallax effects.
- **Curated Gallery**: A specialized "My Work" section featuring Nature, Urban, and Fashion photography.
- **Interactive Storytelling**: "Behind the Lens" section exploring the philosophy of the artist.
- **Service Portfolio**: Detailed service breakdown for Fine Art and Commercial photography.
- **Responsive & Performant**: Fully optimized for all devices with high-performance animations.
- **Premium Aesthetics**: Dark mode, custom typography, and a refined color palette.

## 🛠️ Technology Stack

- **Core**: [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform) + ScrollTrigger
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Lumination.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

## ✒️ Design Philosophy

> "Every shadow tells a secret that light alone cannot reveal."

Lumination is built on the principle of **minimalism**. By stripping away color and excessive light, we focus on the raw essence of the subject—its form, texture, and emotion.
